# PmergeMe (Ford-Johnson Algorithm)

42 커먼코어 CPP Modules 과제로, C++로 구현한 포드-존슨 정렬 알고리즘(merge-insertion sort)입니다.

## 프로젝트 개요

- **과제:** CPP09 - ex02
- **인원:** 개인 프로젝트
- **핵심 목표:** 비교 횟수를 이론적 최솟값에 가깝게 줄이는 정렬 알고리즘 구현

## 주요 구현 내용

### 정렬 로직
- 원소들을 쌍으로 묶어 비교한 뒤, 큰 값들의 집합(메인체인)과 작은 값들의 집합(펜딩)으로 분리
- 메인체인을 재귀적으로 정렬하는 원래 방식은 재귀 호출에 따라 시간 복잡도가 늘어나는 단점이 있어, 대신 병합정렬(merge sort) 방식으로 메인체인을 정렬하되, 구간 크기가 일정 수준(48개) 이하로 작아지면 삽입정렬로 전환하는 하이브리드 방식을 적용해 효율을 개선
- 펜딩 원소를 메인체인에 삽입할 때는 자콥스탈 수열(Jacobsthal number)로 삽입 순서를 정해 비교 횟수를 최소화
- 삽입 위치를 찾을 때는 순차 탐색 대신 이진 탐색을 사용해 비교 횟수를 추가로 절감

### 자료구조 비교 (vector vs deque)
- 동일한 정렬 로직을 std::vector와 std::deque 두 가지 컨테이너로 각각 구현해 성능을 비교
- 원소 개수를 늘려가며 실행 시간을 측정한 결과, **원소 수가 늘어날수록 deque가 vector 대비 상대적으로 느려지는 경향**을 확인
- vector는 인덱스로 원소에 바로 접근할 수 있는 반면, deque는 내부적으로 여러 블록에 나뉘어 저장되어 있어 접근할 때 순차적으로 거쳐가야 하는 구조라, 이 차이가 성능 차이로 이어진 것으로 판단
- 이를 통해 같은 알고리즘이라도 어떤 자료구조를 쓰는지에 따라 실제 성능이 달라질 수 있다는 것을 확인

## 기술 스택

- 언어: C++
- 자료구조: std::vector, std::deque
- 알고리즘: merge-insertion sort, 이진 탐색, 자콥스탈 수열

## 배운 점

비교 횟수를 줄이는 알고리즘을 설계하는 것만큼, 그 알고리즘을 어떤 자료구조 위에서 돌리는지도 실제 성능에 영향을 준다는 것을 확인했습니다. 또한 정석적인 재귀 방식이 항상 최선은 아니며, 문제 특성에 맞게 구현 방식을 바꿔 효율을 개선할 수 있다는 것도 배웠습니다.
