# miniRT

42 커먼코어 과제로, C언어로 구현한 레이트레이싱(Ray Tracing) 3D 렌더링 엔진입니다.

## 프로젝트 개요

- **기간:** 2025.05.24 ~ 2025.06.19
- **인원:** 2인 팀 프로젝트
- **담당 파트:** 도형(구·평면·실린더 등) 파싱, 카메라 및 조명 구현, 카메라·물체 회전 구현

miniRT는 카메라, 조명, 다양한 3D 도형(구, 평면, 실린더 등)으로 구성된 장면(scene)을 파일로 입력받아, 광선-객체 교차 연산을 통해 3D 장면을 2D 화면에 렌더링하는 프로젝트입니다.

## 주요 구현 내용

### 조명(Lighting) 처리
- Phong 조명 모델을 기반으로 ambient(주변광) / diffuse(난반사) 요소를 계산해 물체 표면의 밝기를 구현
- 광원의 위치, 색상, 밝기 비율(bright_ratio)을 별도 구조체로 관리해 씬(scene)마다 다른 조명 조건을 설정할 수 있도록 처리
- 광선이 광원에 도달하기 전 다른 물체에 가려지는지 판단해 그림자를 표현

### 도형 파싱 및 렌더링
- .rt 확장자의 씬 파일을 파싱해 카메라, 광원, 도형(구·평면·실린더) 정보를 구조체 형태로 저장
- 각 도형별로 광선과의 교차 여부 및 교차 지점을 계산하는 hit 판정 로직을 구현 (예: 구는 이차방정식의 판별식으로 교차 여부 판단)
- 교차 지점의 법선 벡터, 반사율(albedo) 등을 hit_record 구조체에 기록해 조명 계산에 활용

### 회전 구현 (카메라 & 물체)
- 벡터를 X·Y·Z 축 기준으로 회전시키는 공용 함수(`rotate_xyz`)를 구현하고, 이를 카메라와 물체 양쪽에 재사용
- 카메라 회전 시에는 방향 벡터와 업(up) 벡터를 회전시킨 뒤, 외적으로 수평·수직 기저 벡터와 뷰포트 위치를 다시 계산해 시점 전환을 구현
- 물체 회전 시에는 동일한 함수로 물체의 위치·축 벡터를 회전시켜, 키 입력에 따라 장면 속 물체가 회전하는 애니메이션을 구현
- 하나의 회전 함수를 카메라와 물체 양쪽에서 재사용하면서, 함수를 특정 대상에 종속되지 않도록 범용적으로 설계하는 것의 중요성을 체감

## 기술 스택

- 언어: C
- 그래픽스 라이브러리: MiniLibX
- 수학: 벡터 연산(내적, 외적, 정규화), 광선-객체 교차 판정

## 빌드 및 실행 방법

```bash
make
./miniRT [파일 경로].rt
```

## 배운 점

벡터의 내적·외적과 회전 변환 같은 수학적 개념을 코드로 직접 구현하며 3D 그래픽스의 기초를 이해할 수 있었습니다. 특히 회전 함수(`rotate_xyz`)를 카메라와 물체 양쪽에서 재사용하면서, 특정 대상에 종속되지 않도록 범용적으로 설계하는 것이 코드의 재사용성과 유지보수성을 높인다는 것을 체감했습니다. 카메라 회전의 경우 방향 벡터 하나를 바꾸는 것이 기저 벡터, 뷰포트, 광선 생성 방식까지 연쇄적으로 영향을 준다는 것도 확인할 수 있었고, 여러 값이 서로 연결된 시스템에서는 하나의 변경이 어디까지 전파되는지 정확히 파악하는 것이 중요하다는 것을 배웠습니다.
